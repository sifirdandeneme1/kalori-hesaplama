# Kalori Hesaplama v2

Ömer için hazırlanmış çevrimdışı Android kalori takip uygulaması.

## v2 yenilikleri

- Her besinde 100 gram/100 ml temel kalori değeri
- Aynı besine birden fazla adet, dilim, paket veya porsiyon ölçüsü
- Besin eklerken gram/ml ya da hazır porsiyon seçimi
- Eski besin kayıtlarını otomatik olarak yeni yapıya dönüştürme
- Bugün, Besinler ve Ayarlar sekmelerinden oluşan yeni arayüz
- Ayarlanabilir dakika başına egzersiz kalorisi
- GitHub eşitlemesinde yeni `version: 2` veri biçimi

## APK derleme

GitHub'a yükledikten sonra **Actions > Kalori Hesaplama APK > Run workflow** yolunu kullanın. Çıktıdaki `Kalori-Hesaplama-APK` artifact'i içinde APK bulunur.
